# Omnifood – Healthy Meal Delivery Website

Omnifood is a fully responsive food delivery website that helps users discover healthy meal options and explore personalized meal plans.

### 🌐 Live Demo

[Visit Omnifood Website](https://omnifood-purnvashi.netlify.app/)

### ✨ Features

* Fully responsive design for desktop, tablet and mobile.
* Modern and clean user interface.
* Interactive navigation menu.
* Meal plans and pricing sections.
* Customer testimonials.
* Newsletter signup section.

### 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

### 📌 Project Status

Currently improving the website by adding JavaScript functionality, enhancing user interactions and optimizing performance.
